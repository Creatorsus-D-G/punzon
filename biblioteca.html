Punzón
—

Biblioteca local · IndexedDB

Tus fuentes viven en tu dispositivo

Cada tarjeta muestra la fuente real: se genera un TTF en memoria y se registra con FontFace para que veas tus propios glifos, no una maqueta. Exporta el JSON para versionarlo en Git o llévatelo a otro equipo.

Cómo se guarda tu trabajo

Sin cuenta, sin nube y sin telemetría. Aquí está exactamente qué ocurre cuando editas, borras o arrastras una tarjeta.

Autoguardado

Cada cambio en el editor se escribe en IndexedDB tras una breve pausa. Si el sistema cierra la pestaña para liberar memoria, el proyecto sigue intacto.

Deshacer al borrar

Eliminar es reversible: el aviso mantiene los proyectos en memoria unos segundos y ofrece restaurarlos con un solo toque.

Orden manual

Arrastra una tarjeta sobre otra para reordenar. El orden se guarda en el dispositivo y el selector cambia solo a «Orden manual».

JSON portable

Exportar genera un .punzon.json con métricas, glifos y kerning. Importarlo en otro equipo reconstruye la fuente exactamente igual.
